# 夜航英语 · Nightflight

**给有英语基础、下班后却没精力学习的人，一个每天都容易开始的英语入口。**

夜航英语是一款可以在电脑和手机上使用的英语学习应用。它面向有英语四级基础、希望积累词汇和改善日常表达的人：每天选择适合自己精力的任务，通过一个短故事或生活问题学习单词，再用回忆练习和一句自己的表达把它们留下来。

例如，你可以读一段“如何拒绝同事临时请你帮忙”的短文，学习 **reluctant、resentment、boundary** 等词及搭配，然后尝试表达：

> I'm reluctant to take on another task tonight. I need to set a boundary and leave on time.
>
> 我不太愿意今晚再接一项任务。我需要划定界限，准时下班。

项目当前提供可运行的首版：**4 个完整主题、32 个目标词、完整学习流程和本机进度保存**。打开即可使用，不需要注册账号或配置 AI 密钥。

## 怎么学

1. **选今天的精力。** 有空就学约 8 分钟，忙时约 4 分钟，很累时只做约 1 分钟的复习。
2. **先找回旧词。** 应用优先安排到期复习；积压较多时会减少新词，避免任务越堆越重。
3. **读一段有意思的内容。** 每篇约 100 个英文词，围绕职场边界、睡前刷手机、选择和日常观察展开。可以听全文、展开中文、点击单词查看含义。
4. **记单词，也记搭配。** 词卡提供发音、音标、含义、搭配和例句。已经熟悉的词可以跳过。
5. **隐藏答案，再想一遍。** 输入单词完成填空。需要时可查看提示，错词会在练习末尾再出现一次。
6. **用英语说一句自己的话。** 写下想法，对照参考表达自查；完成后查看本次收获，安心结束。

你随时可以暂停。关闭或刷新后，首页会提供“接着学”的入口。

### 学习量按精力调整

| 模式 | 预计投入 | 最多新词 | 最多到期复习词 |
|---|---:|---:|---:|
| 刚刚好 | 8 分钟 | 8 个 | 12 个 |
| 有点忙 | 4 分钟 | 4 个 | 6 个 |
| 很累了 | 1 分钟 | 0 个 | 4 个 |

时长是任务规模的估计，实际用时由你决定。复习积压时，新词会少于上限；没有到期词的疲惫日，可以直接休息。

## 有哪些功能

- **电脑与手机一起用：** 桌面侧栏、手机底部导航，页面自动适配屏幕；支持 PWA 安装。
- **在语境中学词：** 4 个主题包含词汇、搭配、短文、中文解释、例句和回忆练习。
- **主动回忆与间隔复习：** 成功回忆后按 1、3、7、14、30 天逐步安排；答错或使用提示的词更早回来。
- **真实的学习记录：** 分开记录“待巩固”“能回忆”“较稳定”，展示实际投入、首次回忆正确率和自己写过的表达。提示后答对、末尾重练不抬高首次回忆正确率。
- **提醒与恢复：** 页面内提醒、可导入系统日历的每日提醒、未完成练习恢复。
- **进度备份：** 本机保存，支持 JSON 导出和导入，方便手动迁移到另一设备。
- **离线与朗读：** 首次加载完成后可缓存学习内容；英语朗读使用设备提供的语音。

## 在电脑上运行

准备 **Node.js 18 或以上版本**，运行：

```bash
git clone https://github.com/tianley350-source/nightflight-english.git
cd nightflight-english
node server.mjs
```

然后在浏览器打开 **http://localhost:4173**。

项目无需安装依赖。也可以使用 `npm start` 启动，按 `Ctrl+C` 停止服务。没有使用 Git 时，可以在 GitHub 中选择 Code → Download ZIP，解压后在项目目录运行 `node server.mjs`。

如果 4173 端口已被占用，Windows PowerShell 可使用：

```powershell
./start.ps1 -Port 4174
```

或设置环境变量 `PORT` 后运行 `node server.mjs`。如果系统限制 PowerShell 脚本，直接使用 Node.js 启动即可。

## 在手机上使用

**本地体验：** 手机和电脑连接同一 Wi-Fi，保持电脑服务运行，在手机浏览器打开 `http://电脑的局域网IP:4173`。Windows 可以运行 `ipconfig` 查找当前网络适配器的 IPv4 地址，电脑防火墙需允许该端口在局域网中访问。手机上的 `localhost` 指向手机自身，不能用来访问电脑服务。

**安装使用：** 将网页部署到 HTTPS 站点后，电脑和 Android 可通过支持 PWA 的浏览器安装；iPhone 可在 Safari 中选择“分享 → 添加到主屏幕”。PWA 安装和离线缓存需要 HTTPS 或 localhost；局域网 HTTP 地址可以体验学习界面，但不能完整启用这些能力。

## 提醒和进度怎么保存

- 页面内提醒只在应用页面打开且可见时触发，每天最多提醒一次。
- 在“学习偏好”导出日历提醒并导入系统日历后，可由日历在应用关闭时提醒；提醒行为由日历应用管理。
- 进度保存在当前浏览器，不同设备各自保存。换设备时，可先导出备份，再在另一设备导入。导入会替换目标设备的记录，未完成练习不随备份迁移。

## 当前版本的范围

这是一个用于验证学习体验的首版，现有内容为四级进阶固定难度，自动调整每日任务量与复习间隔。开放表达采用参考答案自查。

后续计划包括：扩展主题和词库、增加陌生语境回忆题与水平测评、账号云同步、应用关闭后的后台推送，以及 AI 表达反馈。当前尚未连接这些服务，也没有提供语音识别或发音评分。

“较稳定”表示连续 3 次成功回忆，不代表永久掌握。英语朗读的音色及离线能力取决于设备语音；清理浏览器数据会影响本机记录，建议定期备份。

## 给开发者

采用原生 JavaScript ES Modules、CSS、SVG、LocalStorage 和 Service Worker，电脑和手机共用一份前端。Node.js 服务用于本地静态预览。

```text
index.html           网页入口
app.js               页面交互与学习流程
styles.css           双端界面样式
data.js              主题、词汇、例句和练习内容
core.js              任务规划、间隔复习与数据校验
sw.js                离线缓存
manifest.webmanifest PWA 配置
server.mjs           本地静态服务
tests/               学习规则测试
```

运行测试：

```bash
npm test
```

目前 9 项规则测试通过，浏览器验证覆盖完整学习流程、暂停恢复、备份、提醒、离线重新打开，以及 6 种屏幕宽度。实体手机和长期学习效果仍需实际使用验证，详见验收记录。
